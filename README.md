Calculadora de operaciones básicas

Pequeña aplicación de consola desarrollada en Python como parte de mi ruta de aprendizaje en programación. Su objetivo es poder realizar cálculos matemáticos básicos, validando las entradas numéricas para evitar errores de ejecución.

Tecnologías utilizadas
**Python 3.x** (Manejo de lógica, bucles `while`, bloques `try-except`, evitar la división entre cero y la raíz de números negativos).

Funcionalidades
* Cálculos básicos de matemáticas(suma, resta, multiplicación, división, exponente y raíz cuadrada)
* Validación robusta de datos de entrada (bloqueo de letras, ceros y números negativos).
* Poder realizar varias operaciones tras terminar alguna y finalizar cuando el usuario lo desee.
* Formato de salida limpio y profesional simulando una aplicación de consola interactiva.
